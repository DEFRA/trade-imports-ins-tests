# Accessibility scans

## Excluded conditional-reveal radios

govuk-frontend's conditional-reveal radios set `aria-expanded` on the radio input in its `radios.mjs`, and axe's `aria-allowed-attr` rule rejects that. This is an upstream disagreement in component code the service does not own, not a defect in the service.

The scans exclude only the inputs that carry it, through the selectors in `utils/a11y-exclusions.ts`:

| Selector                               | Page             | Why it is excluded                                                                        |
| -------------------------------------- | ---------------- | ----------------------------------------------------------------------------------------- |
| `govukConditionalRevealRadioOnOrigin`  | Origin of import | The region of origin code requirement radio opens a conditional reveal.                   |
| `govukConditionalRevealRadiosOnReason` | Import reason    | Four of the five reasons open a conditional reveal, so four radios carry `aria-expanded`. |

## Excluded file upload button

govuk-frontend's file upload script (`file-upload.mjs`) replaces the file input with a button. The button's status text ("No file chosen" or the file's name) and its "Choose file" pseudo-button are separate blocks with no space between them. axe 4.14 runs `label-content-name-mismatch` by default and joins those blocks without a space. It reads the visible text as "No file chosenChoose file or drop file", and does not find that in the accessible name.

The browser's accessible name is "Attachment , No file chosen Choose file or drop file". That contains the visible text, so the button meets WCAG 2.5.3 Label in Name. This is a fault in axe's text extraction on component code the service does not own, not a defect in the service. It appears in govuk-frontend 6.5.1 and 6.6.0, with axe-core 4.14.1.

The scans of the accompanying documents page exclude the button through `govukFileUploadButtonOnDocuments` in `utils/a11y-exclusions.ts`. Delete the exclusion once a release of axe or govuk-frontend no longer reports it.
