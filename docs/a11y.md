# Accessibility scans

## Excluded conditional-reveal radios

govuk-frontend's conditional-reveal radios set `aria-expanded` on the radio input in its `radios.mjs`, and axe's `aria-allowed-attr` rule rejects that. This is an upstream disagreement in component code the service does not own, not a defect in the service.

The scans exclude only the inputs that carry it, through the selectors in `utils/a11y-exclusions.ts`:

| Selector                  | Page             | Why it is excluded                                                                        |
| ------------------------- | ---------------- | ----------------------------------------------------------------------------------------- |
| `conditionalRadioInput`   | Origin of import | The region of origin code requirement radio opens a conditional reveal.                   |
| `conditionalReasonRadios` | Import reason    | Four of the five reasons open a conditional reveal, so four radios carry `aria-expanded`. |
